**A weekly cross-check of Google, DeepSeek, Moonshot, xAI and Mistral against LiteLLM's model list, as a signal to re-read a provider's page.** (#820) `scripts/price-crosscheck.mjs`, run by the same scheduled CI job as `price-drift.mjs`, reads LiteLLM's public `model_prices_and_context_window.json` and reports, for the providers `price-drift.mjs` cannot read: a LiteLLM chat model the catalogue does not price (missing), an input, output or cache-read rate that differs from the catalogue's (differs, with the catalogue's source page and read date beside it), and a file with nothing for a provider (unread). **LiteLLM is a signal, not a source: nothing is copied and the script never writes `pricing.ts` or any file.** A LiteLLM rate that equals the row's base, its rate in force today or any of its tiers (DeepSeek's peak hours, a long prompt) is agreement, reported as a note naming the tier, and a row the catalogue has retired is a note and is not compared. Ids are matched exactly after taking off LiteLLM's provider prefix, never by resemblance; a catalogue model LiteLLM does not list is a note. On the weekly schedule a differing rate or an unread file fails the run and a missing model only reports; on other runs it never fails. `CONFIRMED_DIFFERENCES` records a row a person re-read and found right. `raw.githubusercontent.com` is now decided in `trusted-hosts.test.js` as public data, no credential. Documented in `docs/releasing.md` and `docs/pricing-dataset.md`. `price-crosscheck.test.js` runs a fixture LiteLLM file (a missing model, a differing rate, a matching rate, a provider out of scope) against a stand-in catalogue; the plants (a missing model not reported, a differing rate not reported, an equal rate reported, a write to `pricing.ts`, an out-of-scope provider reported, tiers ignored, `retired` ignored) are recorded on the pull request.
