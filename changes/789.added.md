**`trazum bill --receipt --send <url>` posts the receipt to an organisation's HTTPS endpoint, and nothing else leaves.** (#789) The body is the bytes `--receipt` writes, one `POST`, one attempt, no retry and nothing in the background. The key is read from `TRAZUM_RECEIPT_KEY` as a bearer header, is not accepted as a flag and is removed from anything printed, a response body included. The URL goes through `watch --webhook`'s own `checkWebhook` (https except on loopback, no credentials in the URL), and a redirect is refused. The receipt is written before the send, so a refusal or an error leaves it in place; the run then exits 3, and stderr carries the status and the response body, never the request headers. `--send` without `--receipt` is refused by name. `receipt-send.ts` is added to the outbound modules `SUPPORT.md` lists. Documented in `docs/commands.md`, under `bill`; messages in English and Spanish. `bill-send.test.js` receives the bytes on a local server, and the plants (a prompt in the request, the key printed, a redirect followed, plain http to a remote host accepted) are recorded on the pull request.
