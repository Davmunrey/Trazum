**A pull request adds its changelog entry as a file in `changes/`, and the release folds them into `CHANGELOG.md`.** (#847) Every pull request used to edit the same `## Unreleased` section of a 1.1 MB file, so two open pull requests always conflicted there, and a merge after a release once put an entry inside a published version (#666). Now each change is `changes/<issue>.<kind>.md`; `prepare-release.mjs` folds them under the new version, newest issue first, and deletes them; the site's changelog page shows them as pending. `pr-readiness.mjs` and `npm run done` require one such file and refuse a line added to `CHANGELOG.md` outside a release. The 27 entries that were under `Unreleased` moved to files verbatim: folded back, they are the same text.
