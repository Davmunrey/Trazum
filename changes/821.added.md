**`trazum session-guard` is a Claude Code hook that warns once, then stops a session, at two dollar figures you set.** (#821) `trazum session-guard install --warn 5 --stop 15 --on-cannot-tell fail-open` writes one hook to `~/.claude/settings.json`, on the `UserPromptSubmit` and `PreToolUse` events. Each time it runs it reads the session's transcript and its subagents' transcripts, converts them as `from-claude-code` does, and prices them at the bundled, dated catalogue. Under `--warn` it is silent. At or over `--warn` it says so once per session, as `{"systemMessage": ...}` at exit 0. At or over `--stop` it blocks every time, with exit code 2 and the reason on standard error. Both are the forms Claude Code's hooks page (code.claude.com/docs/en/hooks, read 2026-11-19) documents, and the page and date are in a comment in `session-guard.ts`. **Nothing has a default**: a missing `--warn`, `--stop` or `--on-cannot-tell` is refused by name, and so is a `--warn` that is not below `--stop`. A transcript that cannot be read, a missing one, and a model the catalogue has no price for follow `--on-cannot-tell`, with the meaning it has on `gateway`, and never count as $0; calls that were priced count as a floor, so an unpriced model cannot hide a stop. Every figure is worded as API-equivalent cost, not what was paid, in English and Spanish. It reuses `proactive`'s door: the same write function, backup, JSON-as-data reading and record in `~/.trazum/proactive.json`, so `uninstall` removes exactly its own hook and the containers it made, and a hook of yours that mentions `session-guard` is never taken for its own. "The warning was given" is a file in the status line's cache directory and nowhere else. It loads no config and refuses `--pricing` and `--pricing-live`; nothing leaves the machine. Not available on Windows. The hook reads the whole transcript on every prompt and tool call, and how long that takes has not been measured. Documented in `docs/commands.md`; the command count in the README, the plugin page, `docs/licensing.md` and the web app's sample text moves from 57 to 58. Tests are in `packages/cli/test/session-guard.test.js`, on made-up transcripts with the money worked out by hand ($25 per million output tokens on Claude Opus 5, so 100,000 tokens is $2.50) and temporary homes only. Planted one at a time and put back, each caught by the test named: no warning given (`warns between the figures...`, `warns at exactly the warning figure`), warning repeated (`gives the warning once per session...`), no stop (`blocks at exactly the stop figure...`), stop below the threshold (`does not block just under the stop figure`), an unpriced model priced at $0 (`never prices a model with no price at zero...`), and the install touching another hook (`adds the hook to both events and touches no other hook...`).
