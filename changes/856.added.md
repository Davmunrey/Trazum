- **`trazum model-pricing` reads the contracted rates your organisation already gave Claude Code** in its `modelPricing` managed setting and writes them as a pricing overlay, so `bill` and every command that takes `--pricing` show the figure Claude Code shows. What the table cannot say (batch, fast mode) keeps the catalogue's figure and is named per model; a key it cannot place, a row Claude Code would drop and a rate of zero are named and priced nowhere. A receipt line priced by any overlay now carries the overlay's date rather than the catalogue's. (#856)
