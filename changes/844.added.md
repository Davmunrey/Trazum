**`bill --prom-out` writes the bill in the Prometheus text format, and a Grafana dashboard reads it.** (#844) Teams that already run Grafana want the spend in the same place. The file is the `--otlp-out` payload written as text, sample for point, for the node exporter's textfile collector: Trazum pushes nothing. Each closed UTC day is its own series, labelled `trazum_day`, with no timestamp, because Prometheus refuses a scraped sample stamped a day back. Every cost sample keeps `trazum_cost_basis="api-equivalent"`, what could not be priced is its own metric, and what a day still being measured held is a gauge of its own. `docs/grafana/trazum-bill.json` charts it, and says on every panel with money that it is API-equivalent. `bill-prom.test.js` holds that the samples add to the bill, that each matches its OTLP point, that a project name with a quote and a backslash survives, and that the dashboard queries no metric or label the file does not write.
