**No workflow grants a write permission at the top of its file.** (#873) `cla.yml`, `backfill-releases.yml`, `pr-guide.yml` and `labels.yml` gave their writes to the whole file, so a job added beside the one that needs them would have inherited them. Each write is now on its job, the top of every file is read-only, and a test holds it. OpenSSF Scorecard's first run found the first two.
