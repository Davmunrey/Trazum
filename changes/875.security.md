**The files on a release are attested: who built them, from which commit.** (#875) The `.vsix`, the `.mcpb`, the pricing dataset, the bill of materials and `SHA256SUMS` carry one build-provenance attestation, signed by the release workflow and attached as `trazum-v<version>.sigstore.json`; `gh attestation verify` checks a file against it (RELEASES.md, "Checking them").
