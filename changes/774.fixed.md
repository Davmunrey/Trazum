**The Gemini CLI line says where it installs from, and was run once to see that the server works.** (#774) `gemini extensions install https://github.com/TrazumAPP/Trazum` installs the source of the repository's latest release, not its default branch as `docs/agents.md` and the download page said in five languages. Run once with Gemini CLI 0.70.0 in an empty home folder, it installed the extension at the 3.0.5 release, and the server it starts answered `initialize`, `tools/list` and a `check_prompt` call. `docs/agents.md` now also says what Gemini CLI does while a new release carries only its bill of materials, and names the test that holds the install snippets, `install-snippets.test.mjs`, where it used to give a path that does not exist.
