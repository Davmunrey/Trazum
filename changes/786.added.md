Its daily, weekly, monthly and session reports are read, focused on Claude Code or across every agent, written against ccusage 20.0.51's source and tested on its real output. ccusage's own figure is printed beside the catalogue's, model by model, and never used to price. The usage log `from-ccusage` writes is read like any other, so what reads it counts its records as calls, as it does the rows of Anthropic's usage report.
