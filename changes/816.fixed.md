**The Homebrew formula waits until npm's packages are a day old.** (#816) Homebrew installs with `npm --min-release-age=1`, and on 2026-11-19 `brew install davmunrey/trazum/trazum` failed on a Mac with `ETARGET: No matching version found for @trazum/core@3.0.1 with a date before ...`, because the tap had moved to a version npm had published seven hours earlier. `scripts/homebrew-formula.mjs` now reads the publish time of the CLI and of every `@trazum/` dependency it pins, and refuses to write the formula before the youngest is a day old, naming the moment it may. `RELEASES.md` says so in the Homebrew step.
