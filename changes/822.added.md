**`trazum waste` points out the waste in a coding-agent session, priced, and changes nothing.** (#822) `trazum waste <session>.jsonl` reads a Claude Code transcript and the transcripts of its subagents and names three costs: a file read again (the same path and range as an earlier read in the same conversation, no edit of it between, not an errored read), MCP servers loaded and never called, and a CLAUDE.md carried on every turn. It is a command of its own rather than a section of `bill`, because its answer is a short list of named costs each with the reason it is or is not priced, and `bill` answers whose spend a slice is. Prices are at the bundled, dated catalogue as API-equivalent cost, through `profileUsage`; it loads no config and refuses `--pricing`, `--pricing-live` and `--config`. **A saving is computed from the session's own counts and never a percentage taken from elsewhere**: a repeated read is priced by the prompt growth across the call that made it (`P(next) - P(this) - output(this)` tokens), carried on every later call of that conversation until the prompt shrinks (a compaction), as the difference between the conversation priced as it was and priced without those tokens. It is a lower bound, priced only where the call made no other tool call, and the rest are counted and said to be unpriced. **MCP servers are named and not priced**, because a server's tool-definition tokens are not recorded in a transcript; the loaded list is read from the `deferred_tools_delta` and `mcp_instructions_delta` attachments, whose field names were checked on 2026-11-19 against a real Claude Code transcript, and from an `mcp_servers` list on a `system` line, which that transcript did not have; `--mcp-servers a,b` names them instead and the output says so. **CLAUDE.md is the one estimated figure**: its size is a `stat` of the file in the session's directory (or `--claude-md`), its tokens are bytes over the estimator's divisor of 4, and the cost is shown with the estimator's published band, 33%, either side. It recommends and edits no file, and reads counts and paths only: no message text, command, tool result or file content reaches the report, held by a test that plants a secret in each. `--min-reads <n>` (default 3) chooses what is listed; `--json` prints a document with `schemaVersion` and `kind: "trazum-waste"`, held in both directions to its table in `docs/json-output.md` and listed in `docs/format.md`, whose count of emitted documents moves from twenty-five to twenty-six. Documented in `docs/commands.md`; messages in English and Spanish; the command count moves from 58 to 59 wherever it is stated. Tests are in `packages/core/test/session-waste.test.js` and `packages/cli/test/waste.test.js`, on made-up transcripts in temporary directories with the money worked out by hand (two repeated reads of 3,000 tokens each on Claude Opus 5 are $0.042; a 4,000-byte CLAUDE.md over six calls is $0.0145). Planted one at a time and put back, each caught by the test named: a write between two reads ignored (`does not count a read that follows a write to the same file`), the read range ignored (`does not count a different range of the same file as the same read`), an errored read counted (`ignores a read the tool reported as an error`), every conversation merged (`keeps every conversation apart...`), no reset at a compaction and the output tokens not subtracted (`prices the context a repeat added and carried...`), a repeat priced although other tool calls shared its growth (`counts a repeat made beside other tool calls and does not price it`), a server given a price (`does not price it: the definitions are not in the transcript`), the band's sign reversed (`prices the tokens a size implies...`), `--min-reads` ignored (`lists only files read at least --min-reads times...`), a removed tool still loaded (`forgets a tool the transcript later says was removed`), an unreadable call counted as free (`says it cannot tell when a call could not be read as usage...`), the working directory copied into the report (`carries nothing of what was said, run or returned into the report`), the CLAUDE.md content opened or a file written (`opens no file for its content except the transcripts`), a pricing overlay accepted (`refuses a pricing overlay, a missing path...`) and a documented JSON field removed (`documents every field in docs/json-output.md, and emits no other`). Not planted: the check that the transcript pairs with its usage line for line, which has no input that can break it short of a defect in the converter. Not measured: how long it takes on a very large transcript, and what share of real sessions' repeats are priced rather than counted.
