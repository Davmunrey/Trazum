**Every change to main needs the other maintainer's approval.** (#920) The branch ruleset asked for zero approvals because, with one maintainer, one deadlocked the repository: GitHub does not let an author approve their own pull request. With a second maintainer since 2026-11-22 it asks for one again, so a change, Dependabot's included, merges only when the maintainer who did not open it approves.
