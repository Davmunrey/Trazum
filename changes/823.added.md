**The Claude Code status line says how much of your plan's window is used and when it resets.** (#823) On a subscription the question is when you run out, not what a call cost. Claude Code hands the status line `rate_limits` on a Pro, Max or Ultra plan, or behind a gateway that sets a spend limit, and the line now shows it beside the session's figure: `5h 23%, resets 14:20 · 7d 41%, resets Sat 09:00`, and `spend 62% of $500/month, resets Mar 1` where a spend limit is set. Only what Claude Code sent is shown: a window without its percentage or its reset, or whose reset has passed, is left out, and a percentage is rounded down, so a window at 99.6% is not shown as used up. On an API key, and before a session's first response, Claude Code sends none and the line shows no plan figure: Trazum keeps no table of plan limits and works out no counter from tokens. Field names and units are from Claude Code's status line documentation, read on 2026-11-20. The status line suite runs the script on each case; planting a window whose reset has passed, a window without a percentage, a percentage rounded up, or the separator printed with nothing after it each fails it.
