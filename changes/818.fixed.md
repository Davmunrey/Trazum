**Three low-severity findings from a security audit are closed.** (#818) None is a demonstrated loss of a secret or of code execution.
- *`trazum serve` and `trazum gateway` no longer answer a web page that rebinds its own hostname to 127.0.0.1.* Both bound to loopback and read neither `Host` nor `Content-Type`, so a page could send `text/plain` (no preflight) to `POST /cost` and read the measured spend, the budget and the policy verdicts, and the gateway's 402 body carried the standing. A request whose `Host` is not `localhost`, `127.0.0.1` or `[::1]` on the bound port is now a `403`, and a POST that is not `application/json` a `415` (after routing, so an unknown path is still a `404`). **A client that posted without `content-type: application/json` now gets `415`**: `curl -d` needs `-H 'content-type: application/json'`, which `docs/commands.md` now shows. Provider SDKs and the documented clients already sent it. The checks are in `packages/cli/src/loopback-guard.ts`; a Unix socket skips the `Host` check.
- *The web app's operator endpoint is no longer a free choice of model.* With `TRAZUM_LLM_BASE_URL` set to a server that checks no key (Ollama), `llm: { apiKey: "x", model: "any-model" }` ran any model the operator had pulled. On that endpoint a caller's `llm.model` is now used only if the operator listed it in the new `TRAZUM_ALLOWED_LLM_MODELS`; otherwise `TRAZUM_LLM_MODEL` runs. A key still checks nothing on such a server, which SECURITY.md now says. The route's comment, which said the endpoint costs the operator nothing, is corrected.
- *`mirror-to-n0.yml` declares `permissions: contents: read` and checks out with `persist-credentials: false`.* It pushes to N0 with its own secret in the URL, so the GitHub token was unused and sat in `.git/config`. `security.test.js` now fails on any workflow without a top-level `permissions:`.
- *Tests.* `loopback-guard.test.js` sends the rebound request over `node:http` (attacker `Host`, `Origin`, `text/plain`) to both servers; `api.test.mjs` names a model on a keyless operator endpoint; `security.test.js` reads the workflows. Planted and put back: the Host check removed from each server, the content-type check removed from each server, the caller's model honoured again, the `permissions:` block removed, `persist-credentials` set to `true`; each failed the test named for it.
